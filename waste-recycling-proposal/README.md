## Amahlubi Family Holdings · Waste & Gadget Recycling Proposal Site

This project delivers a responsive marketing & proposal site for the **Standard Waste & Gadget Recycling Service** (R1,200 package) offered by Amahlubi Family Holdings.

### Local Development

```bash
npm run dev
```

Navigate to [http://localhost:3000](http://localhost:3000) to preview the experience.

### Production Build

```bash
npm run build
npm start
```

### Tech Stack

- Next.js App Router (TypeScript)
- Tailwind CSS for styling
- Geist variable font via `next/font`

### Key Sections

- Hero banner with company credentials
- Service overview, pricing summary, and deliverables grid
- Community impact workflow and ideal client profile
- Booking checklist with direct contact links

Ready for deployment on Vercel via `npm run build` followed by `vercel deploy`.
